Smart Library Management System

Project Overview
----------------
A Modern C++ based Library Management System that manages books,
members, borrowing, returning, reservations, fines and statistics.

Technologies
------------
Language: C++
Standard: C++17
Build System: CMake
Testing: GoogleTest
Version Control: Git

Project Structure
-----------------
include/  - Header files
src/      - Source files
tests/    - Unit tests
report/   - Project report

Build Instructions
------------------
cmake -S . -B build
cmake --build build

Run
---
build\SmartLibrary.exe
